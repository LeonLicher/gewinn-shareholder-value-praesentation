# Gewinn als Unternehmensziel? – Shareholder Value

Slidev-Präsentation zur Aufgabe **„Finanzwirtschaftliche Zielsetzungen: Shareholder Value – Am Rechnungswesen orientierte Zielsetzungen“ (Gruppe 1)**, Prof. Dr. Juliane Wolf, FH Münster.

## Aufgabenstellung

1. Unzulänglichkeiten der **Gewinngröße als Unternehmensziel** erklären und Gründe für ihre Beliebtheit finden.
2. Erklären, warum Gewinn und Shareholder Value als Ziele nicht (immer) zu identischen Entscheidungen führen.
3. Überlegungen mit Beispielen untermauern – übersichtlich auf **1–2 Folien**.

Literatur: Rappaport, Alfred (1999): *Shareholder Value*, 2. Aufl., Stuttgart, S. 15–24.
